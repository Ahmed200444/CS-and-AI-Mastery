# CS & AI Mastery v5.59 — Visible Key-Idea Examples

- Every key idea in every opened lesson now has a clearly labeled, visible example card.
- Big-O shows separate examples for time complexity, space complexity, growth rate, Big-O, best/average/worst case, O(1), O(log n), O(n), O(n log n), O(n²), and the time-space trade-off.
- The former one-example-first progressive disclosure was removed so key-idea examples are no longer hidden behind “Next example” / “more examples”.
- Concept examples appear before any additional course-native examples.
- Performance is protected by rendering examples only for the lesson the learner actually opens, using CSS `content-visibility` for off-screen cards, and delaying runtime warm-up until browser idle time or user interaction.
- Applies to all 62 course pages, not only DSA.
