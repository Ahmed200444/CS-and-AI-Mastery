# Focused Learning Layout QA — v5.25.0

> Updated by `CALM_FAST_LEARNING_QA.md`: the first-view flow now shows one example at a time and keeps the remaining examples progressively disclosed.

This release reduces cognitive load without deleting lesson depth.

- Every generated lesson keeps its original deep material.
- Default lesson view uses a short **Quick explanation**.
- The lesson objective is surfaced as a compact **Goal** card.
- **Why it matters** is surfaced as a compact card when available.
- Step-by-step reasoning, worked scenarios, pitfalls, interview/practical notes, and self-checks live under collapsed **Learn deeper**.
- Quick explanation text is capped at 165 words before any overflow is moved into Learn deeper.
- Example explanations use one line-by-line layer; duplicate generic explanation layers are suppressed.
- Syntax details are collapsed per source line.
- Line-by-line details auto-open only for examples with four or fewer non-empty lines; longer examples start collapsed.
- All 62 generated course pages load the same shared progressive-learning asset.
