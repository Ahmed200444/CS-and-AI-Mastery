# CS & AI Mastery — v5.66

## Concept-specific learning update

- Concept cards now define the concept shown on the card instead of reusing a lesson-wide fallback sentence.
- Practical, compact usage examples are added when the concept can be demonstrated faithfully in the course language.
- Python references, identity, aliasing, mutation, automatic memory management, indexing, traversal, sets, tuples, list comprehensions and other common concepts have dedicated examples.
- The generator now prioritizes the concept label before the lesson title so unrelated lesson words do not contaminate examples.
- Hardware/cache examples are restricted to hardware-oriented courses instead of appearing in unrelated DSA/backend concepts.
- Code descriptions remain grounded in the code that is actually shown.
