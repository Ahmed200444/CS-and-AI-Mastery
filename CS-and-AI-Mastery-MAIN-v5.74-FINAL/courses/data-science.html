02Data collection & data quality

What you will learn

  • List common data quality problems and why they matter
  • Explain how missing data changes the behavior, result, or engineering decision in a concrete example
  • Connect missing data with duplicates and predict what changes when one assumption changes

Explanation

Data rarely arrives clean: missing values, duplicate rows, inconsistent formats (dates, units), and outliers from data-entry mistakes are the norm, not the exception. Data quality issues silently corrupt every downstream step — a statistic or model built on bad data gives a confident, wrong answer, which is worse than no answer.

Key concepts

missing dataduplicatesdata qualitygarbage in, garbage out

Example

# quality red flags to check first:
# df.isnull().sum()      -- missing values per column
# df.duplicated().sum()  -- exact duplicate rows
# df['date'].dtype       -- is it actually a date, or a string?
Common mistake: Trusting a dataset just because it 'looks complete' in a spreadsheet preview — always explicitly check for nulls, duplicates, and type mismatches before analyzing.
03NumPy fundamentals

What you will learn

  • Create and operate on NumPy arrays; explain why NumPy is fast
  • Explain how ndarray changes the behavior, result, or engineering decision in a concrete example
  • Connect ndarray with vectorization and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

NumPy provides the array — a fixed-type, contiguous block of numbers — and vectorized operations that run in fast compiled code instead of slow Python loops. `arr * 2` multiplies every element without you writing a `for` loop; this vectorization is the performance foundation almost all of Python data science sits on top of.

Key concepts

ndarrayvectorizationboolean indexingVectorized

Example

import numpy as np
arr = np.array([1, 2, 3, 4])
print(arr * 2)          # [2 4 6 8] -- no loop needed
print(arr.mean())       # 2.5
print(arr[arr > 2])     # [3 4] -- boolean filtering
Common mistake: Writing a Python `for` loop over a NumPy array element by element — this throws away the entire speed advantage; use vectorized operations instead.

05Data cleaning

What you will learn

  • Handle missing values and inconsistent data systematically
  • Explain how missing-value strategies changes the behavior, result, or engineering decision in a concrete example
  • Connect missing-value strategies with standardization and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

Cleaning means deciding, deliberately, what to do with each quality problem: drop rows with missing values, fill them with a sensible default (mean, median, or a flag value), standardize formats (dates, casing, units), and remove true duplicates.

Key concepts

missing-value strategiesstandardizationdeduplicationdocument your data cleaning

Example

df['age'] = df['age'].fillna(df['age'].median())
df['email'] = df['email'].str.lower().str.strip()
df = df.drop_duplicates(subset=['user_id'])
Common mistake: Silently dropping all rows with any missing value — this can throw away a large, non-random chunk of your data and bias every result that follows.
06Descriptive statistics

Explanation

Descriptive statistics summarize a dataset in a few numbers: mean and median describe the 'center' (median is robust to outliers, mean isn't), standard deviation describes spread, and quartiles show the distribution's shape.

Professional benchmark addition: These company-use concepts were kept after comparing the course with public syllabi from KHDA-listed Dubai training providers: confidence interval intuition, hypothesis testing, A/B testing, correlation vs causation.

Key concepts

mean vs medianstandard deviationquartilesoutlierssampling intuitiondistribution shapeconfidence interval intuitionhypothesis testingA/B testingcorrelation vs causation

Example

df['price'].describe()
# count, mean, std, min, 25%, 50% (median), 75%, max
# a huge gap between mean and median usually signals outliers
Common mistake: Reporting only the mean when the data is skewed — a single huge outlier can drag the mean far from what a typical row actually looks like; the median wouldn't move nearly as much.

EDA is the systematic first look at a new dataset before you draw any conclusions: check shape and types, look at distributions of each important column, check for correlations, and look for anything surprising.

# a classic bias trap:
# training a resume-screening model on 10 years of past hires

11Model-ready data preprocessing pipelines

Explanation

Model preprocessing converts raw data into stable features: missing-value handling, categorical encoding, numeric scaling, and text/image preparation. Any step that learns statistics must be fit only on training data, then reused unchanged on validation/test and production inputs.

Key concepts

scalingencodingimputationtrain-only fitdata leakage

Example

Workflow: split train/validation first -> fit imputer/encoder/scaler on train -> transform train and validation -> save the fitted preprocessing objects with the model -> apply the same transformations during inference.
Common mistake: Fitting preprocessing on the full dataset before the train/validation split.
