  • Design DP states and transitions and reduce repeated subproblems systematically.
  • Explain how dynamic programming changes the behavior, result, or engineering decision in a concrete example
  • Connect dynamic programming with state and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

Dynamic programming applies when subproblems overlap and optimal answers can be composed from smaller optimal answers. The hardest step is defining a state that contains exactly the information future decisions need.

dynamic programmingstatetransition

Example

#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> values{3, 1, 5, 2, 6, 4, 9};
    vector<int> dp(values.size(), 1);
    int best = 0;

    for (int i = 0; i < static_cast<int>(values.size()); ++i) {
        for (int j = 0; j < i; ++j) {
            if (values[j] < values[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }

        best = max(best, dp[i]);
    }

    cout << best << "\n";
    return 0;
}
