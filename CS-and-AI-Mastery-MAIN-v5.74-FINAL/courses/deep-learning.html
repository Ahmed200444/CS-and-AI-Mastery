03Activation functions

What you will learn

  • Explain why activation functions are necessary and name common ones
  • Explain how ReLU changes the behavior, result, or engineering decision in a concrete example
  • Connect ReLU with sigmoid and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

Without a non-linear activation function, stacking layers would collapse mathematically into a single linear function no matter how many layers you add — depth would be pointless. ReLU (max(0, x)) is the modern default for hidden layers: simple, fast, and avoids a problem older functions (sigmoid) had with 'vanishing gradients' in deep networks.

Key concepts

ReLUsigmoidnon-linearityvanishing gradientstop updating

Example

def relu(x): return max(0, x)
# ReLU(-3) = 0, ReLU(5) = 5 -- 'passes positive signals through, blocks negative ones'
Common mistake: Using sigmoid activations throughout a very deep network — gradients shrink at each layer during backpropagation, making early layers learn extremely slowly (the vanishing gradient problem).

05Gradient descent & backpropagation

What you will learn

  • Explain, at a conceptual level, how a network learns from its loss
  • Explain how gradient descent changes the behavior, result, or engineering decision in a concrete example
  • Connect gradient descent with backpropagation and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

Gradient descent adjusts each weight a small step in the direction that reduces the loss. Backpropagation is the algorithm that efficiently computes exactly how much each weight, even in early layers, contributed to the final loss, using the chain rule from calculus — working backward from the output to the input.

Key concepts

gradient descentbackpropagationchain ruletraining loopgradient intuitionpartial derivative intuitionchain rule intuition

Example

for epoch in range(num_epochs):
    prediction = model.forward(x)
    loss = loss_fn(prediction, y)
    loss.backward()      # backprop: computes each weight's gradient
    optimizer.step()     # gradient descent: nudges weights to reduce loss
    optimizer.zero_grad()
Common mistake: Forgetting to zero out gradients between training steps — gradients silently accumulate across batches, corrupting the update direction.

Explanation

Plain (stochastic) gradient descent takes fixed-size steps in the gradient's direction. Momentum accumulates a 'velocity' across steps, smoothing out noisy updates and helping escape shallow local dips.

Professional benchmark addition: These company-use concepts were kept after comparing the course with public syllabi from KHDA-listed Dubai training providers: RMSProp, learning-rate schedules.

Key concepts

SGDmomentumAdamlearning rateRMSProplearning-rate schedules

Example

optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
# vs the simpler:

Common mistake: Picking a learning rate that's too high (training diverges/explodes) or too low (training crawls) without ever trying a learning-rate range test.

10Attention & the Transformer Architecture

What you will learn

  • Explain why attention replaced sequential recurrence for processing sequences, at a conceptual level
  • Explain how attention changes the behavior, result, or engineering decision in a concrete example
  • Connect attention with self-attention and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

The sequence models covered earlier (RNN-style architectures) process a sequence one step at a time, which makes it hard to connect distant parts of a long sequence -- information from early in a long sentence can fade by the time the model reaches the end, and processing step-by-step is inherently slow to parallelize.

Key concepts

attentionself-attentiontransformer architecturepositional encodingparallelizationlong-range dependency

Example

# Conceptually: in "The cat sat on the mat because it was tired",
# self-attention lets the model directly connect "it" to "cat"
# (not "mat") based on learned relevance -- regardless of the
# distance between them in the sentence, computed all at once
# rather than by carrying information step-by-step through every
# word in between, the way an RNN-style model would have to.
Common mistake: Assuming 'sequence model' automatically means step-by-step recurrent processing -- the shift from recurrence to attention is precisely what unlocked training on today's much larger datasets.
