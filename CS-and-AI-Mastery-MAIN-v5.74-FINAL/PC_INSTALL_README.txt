CS & AI Mastery - PC install

1. Extract the ZIP completely.
2. Open the extracted folder.
3. Double-click INSTALL_ON_MY_COMPUTER.bat.
4. Choose Y.
5. The app installs to:
   %LOCALAPPDATA%\CS-and-AI-Mastery
6. Use the "CS & AI Mastery" desktop shortcut afterward.

This location is local to Windows and avoids OneDrive/Documents sync issues.
GitHub CLI authentication is stored by GitHub CLI on your PC and is not copied into the app folder.

GitHub repository: open the GitHub page, connect your own account, and choose your own repository. No repository is selected automatically.
