# Second Largest Distinct Value

**Course:** Python  
**Type:** Practice exercise  
**Language:** Python

Find the second-largest distinct value in a sequence. Duplicate occurrences of the largest value do not count as a second distinct value; if fewer than two distinct values exist, the function returns `None`.

## Concepts practiced

- One-pass state tracking
- Duplicate handling
- Boundary cases
- Comparing values without sorting the whole input
