# Second Largest Distinct — Python

**Course:** Python  
**Type:** Practice / Exercise  
**Language:** Python

## Task

Return the second-largest **distinct** number. If there are fewer than two distinct values, return `None`.

## Solution

`solution.py` tracks the largest and second-largest distinct values during one pass instead of sorting the whole input.

## Complexity

- Time: `O(n)`
- Extra space: `O(1)`

## How to run

```bash
python solution.py
```
