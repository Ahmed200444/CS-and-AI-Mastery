# Valley Array

**Course:** Python  
**Type:** Practice exercise  
**Language:** Python

Check whether an array strictly decreases to an interior minimum and then strictly increases. Flat sections and a minimum at either edge are rejected.

## Concepts practiced

- Linear array traversal
- Strict ordering conditions
- Boundary validation
- Early failure checks

## File

`real-valley-array.py`

Import `solution` and pass it a list of comparable values.

```python
from importlib import import_module
# Or copy/import the function in your normal Python project.
```
