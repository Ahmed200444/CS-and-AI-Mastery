# FizzBuzz

**Course:** Python  
**Type:** Practice exercise  
**Language:** Python

Build a list for the numbers from `1` through `n`, replacing multiples of 3 with `Fizz`, multiples of 5 with `Buzz`, and multiples of both with `FizzBuzz`.

## Concepts practiced

- `for` loops and `range`
- Conditional branching
- Modulo arithmetic
- Building and returning lists

## File

`fizzbuzz.py`

## How to run

```bash
python fizzbuzz.py
```

The function returns the generated list, so it can also be imported and tested with different values of `n`.
