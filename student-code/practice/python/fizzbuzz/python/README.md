# FizzBuzz — Python

**Course:** Python  
**Type:** Practice / Exercise  
**Language:** Python

## Task

Build the sequence from `1` through `n`. Multiples of 3 become `Fizz`, multiples of 5 become `Buzz`, and multiples of both become `FizzBuzz`.

## Solution

`solution.py` loops once through the numbers and appends either the original number or the required word.

## How to run

```bash
python solution.py
```

## Review

Trace the conditions in their current order. Checking divisibility by 15 first is important because a number such as 15 is divisible by both 3 and 5.
