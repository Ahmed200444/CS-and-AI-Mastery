# Two Sum — Python

**Course:** Data Structures & Algorithms  
**Type:** Practice / Exercise  
**Language:** Python

## Task

Return the indices of two values whose sum equals the target. Return `None` if no pair exists.

## Solution

`solution.py` uses a dictionary named `seen`. For each number, it checks whether the required complement has already appeared.

## Complexity

- Average time: `O(n)`
- Extra space: `O(n)`

## How to run

```bash
python solution.py
```
