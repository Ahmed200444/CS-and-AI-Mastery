# Two Sum

**Course:** Data Structures & Algorithms  
**Type:** Practice exercise  
**Language:** Python

Return the indices of two values whose sum equals the target. The solution stores previously seen values in a hash map so each new value can look up its required complement immediately.

## Concepts practiced

- Hash maps / dictionaries
- Complement lookup
- Single-pass iteration
- Trading extra memory for faster lookup

## Complexity

- **Time:** `O(n)` average
- **Space:** `O(n)`

## File

`dsa-two-sum.py`

The function returns `None` when no valid pair is found.
