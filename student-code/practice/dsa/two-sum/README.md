# Two Sum

**Type:** DSA Practice  
**Language:** Python

## Objective
Return the indices of two values whose sum equals the target. A hash map stores values already seen so each new value can immediately check for its complement.

## Complexity
Average time: **O(n)**  
Extra space: **O(n)**
