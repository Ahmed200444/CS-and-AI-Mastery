# Point Distance from the Origin

**Course:** Object-Oriented Programming  
**Type:** Practice exercise  
**Language:** Python

Create a `Point` object with `x` and `y` coordinates and calculate its Euclidean distance from the origin.

## Concepts practiced

- Correct Python constructors with `__init__`
- Instance attributes
- Instance methods
- Reusing the standard library with `math.hypot`
