# Bank Account State

**Course:** Object-Oriented Programming  
**Type:** Practice exercise  
**Language:** Python

Model a simple bank account whose balance changes through deposit and withdrawal operations, then process a sequence of operations and return the final state.

## Concepts practiced

- Classes and constructors
- Instance state
- Methods that update state
- Input validation
- Driving an object through a sequence of operations

## File

`oop-counter-state.py`

The implementation rejects negative transaction amounts and unknown operation names instead of silently changing state incorrectly.
