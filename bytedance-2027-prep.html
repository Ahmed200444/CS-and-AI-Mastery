Practice requirements

DSA target

Complete about 45–60 well-understood problems: mostly easy, then selected medium problems. Record the pattern, complexity, mistake, and improved solution.

Engineering target

Build one normal backend service before the agent capstone. Include SQL, validation, tests, logging, and a clean README.

AI target

Build one small RAG app and one tool-calling demo before combining everything into a larger agent system.

Required capstone: Procurement Agent + System AI Harness

Build a Python service that receives a purchase request, checks required information, retrieves procurement policy, compares approved suppliers, checks budget, requests human approval, and records every action.

Core tools

  • search_suppliers()
  • read_procurement_policy()
  • compare_quotes()
  • check_budget()
  • create_purchase_request()
  • get_approval_status()

Interview readiness checks

Coding

Explain the brute-force idea, improve it, state time/space complexity, test edge cases, and write readable code.

Software engineering

Explain layers, data flow, testing strategy, reliability, permissions, trade-offs, and how failures are handled.

AI systems

Explain RAG, tool calling, agent state, memory, evaluation, prompt injection, hallucinations, cost, and latency.

Project ownership

Explain what you personally built, the hardest bug, alternatives considered, measurable results, and the next improvement.
