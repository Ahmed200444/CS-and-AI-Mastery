# C++ Programming & DSA — syllabus alignment

This course is an original CS & AI Mastery curriculum, not a copy of any provider syllabus. Coverage was cross-checked against:

- Aptech Learning's public **Programming in C++** outcomes: program structure, standard input/output, classes/objects, conditions, functions, pointers, arrays, overloading, inheritance, polymorphism, exceptions, and OOP applications.
- Aptech's public course catalogue, which separately lists **Data Structures in C**; CS & AI Mastery adapts the data-structure/algorithm progression to modern C++ so language and DSA stay in one track.
- Current Dubai C++ training syllabi and KHDA directory listings, which show C++ training covering fundamentals, control flow, functions, arrays/strings, pointers/dynamic allocation, OOP, inheritance/polymorphism, files, and exception handling.

The CS & AI Mastery version extends that foundation with modern C++ (STL, templates, RAII, smart pointers, move semantics, lambdas, build organization/debugging) and a complete DSA section implemented in C++.
