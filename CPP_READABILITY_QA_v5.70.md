# C++ Readability QA — v5.70

- `using namespace std;` is present in C++ teaching programs.
- `main`, conditionals, loops, functions, classes, and DSA examples use readable multi-line formatting by default.
- Compact syntax remains allowed when the lesson specifically demonstrates that compact construct (for example a ternary expression).
- Native C++ lesson examples are syntax-checked with `g++ -std=c++20 -fsyntax-only`.
