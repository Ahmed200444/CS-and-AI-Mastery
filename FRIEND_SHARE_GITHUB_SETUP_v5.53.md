# Friend Share GitHub Setup — v5.54

This copy is intended for sharing with another learner. The curriculum is unchanged from v5.52.

## GitHub behavior
- GitHub is optional for studying.
- No repository is selected automatically.
- The learner opens `github-setup.html`, connects their own GitHub CLI account, then selects or adds a repository they can write to.
- The selected repository is stored only in browser local storage under `csai-github-preferred-repo`.
- Publishing is blocked until a repository is explicitly selected.
- GitHub credentials remain in GitHub CLI on the learner's computer and are not stored in the project folder.
