# CS & AI Mastery v5.72

## Always-visible learning questions

Every generated study example now includes one concise **Question** block tied to the actual concept/code. The question is shown as normal content when the example is open; it is not an optional quiz panel and it does not display a **Required** badge.

The question generator recognizes common patterns such as prefix sums, frequency counters, two-pointer reversal, duplicate removal, list comprehensions, generators, references/identity, linked lists, binary search, queues/stacks, recursion, SQL filters/joins/grouping, web examples, and command-line examples. Other examples use the example's distinct practical use and concept as the fallback, so questions do not all repeat the same wording.

Lessons now receive one concise question about when the lesson idea should be used and what result/behavior would show it worked. Exercise and project question guidance is also shown as one compact Question block. Existing knowledge-check questions are not duplicated.

All previous v5.71 content quality, scroll performance, runners, Try it yourself workspaces, syntax explanations, GitHub features, progress, and C++ readability remain intact.
