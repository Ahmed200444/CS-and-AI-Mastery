# CS & AI Mastery — Portfolio Projects

This directory is the GitHub-ready portfolio layer for the CS & AI Mastery learning tracks.

## Rules
- Complete the related learning track before attempting its portfolio project.
- Build the project yourself; use hints and documentation when blocked.
- Every finished project should include a clear README, setup instructions, screenshots or demo evidence when useful, tests where appropriate, and a short section explaining engineering decisions.
- Keep projects in this repository under `portfolio/<track>/<project-name>/` so the existing repository connection never needs to change.

## Definition of done

A portfolio project is complete when it has working code, a useful README, reproducible setup, sensible error handling, tests/evaluation appropriate to the project, clean Git history, and an explanation you could confidently give in an internship interview.
