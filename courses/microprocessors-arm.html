01Microprocessor fundamentals & the CPU

What you will learn

  • Define a microprocessor
  • Explain the CPU's role in a computer
  • Relate transistors to processor implementation

Explanation

A microprocessor is a computer's CPU implemented on a single integrated circuit. It fetches and executes instructions, performs arithmetic and logical work, and coordinates data movement with memory and I/O. Modern processors contain very large numbers of transistors connected to implement datapaths, control logic, caches, and other structures.

Key concepts

Example

Common mistake: Treating a microprocessor as the entire computer rather than the CPU that works with memory and I/O.

Architecture defines the programmer-visible contract, including instructions, registers, data types, and behavior. Microarchitecture is how a particular processor implements that contract. Explanation

Processor performance is fundamentally about how long a workload takes. Clock frequency affects cycles per second, while IPC describes how much instruction work completes per cycle. Pipelining can raise frequency, dependencies and stalls reduce IPC, and superscalar or out-of-order execution can expose more parallel work.

10Processor modes, CPSR, endianness & exception overview

What you will learn

  • Name the major classic ARM modes
  • Interpret key CPSR fields
  • Distinguish little-endian and big-endian storage
  • Explain why exceptions change mode

Explanation

Classic ARM has User mode and privileged modes including System, Supervisor, IRQ, FIQ, Abort, and Undefined. CPSR holds condition flags, execution state, interrupt masks, and mode bits. Little-endian stores the least-significant byte at the lower address; big-endian reverses that order. Exceptions enter an appropriate privileged mode so handlers can use protected state.

Key concepts

User modeSVCIRQFIQAbortUndefinedCPSRendianness

Example

val = 0x12345678  # 32-bit test word
little_endian = [val & 0xFF, (val >> 8) & 0xFF, (val >> 16) & 0xFF, (val >> 24) & 0xFF]  # LSB first
big_endian = [(val >> 24) & 0xFF, (val >> 16) & 0xFF, (val >> 8) & 0xFF, val & 0xFF]  # MSB first
print(little_endian)  # Output little-endian byte array
print(big_endian)  # Output big-endian byte array
Common mistake: Reading the ARM I and F CPSR bits as interrupt-enable bits; in classic ARM, a set mask bit masks/disables that interrupt.
