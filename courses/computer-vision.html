01Images as numerical tensors

What you will learn

  • Explain how an image is represented as numbers a model can process
  • Explain how tensor changes the behavior, result, or engineering decision in a concrete example
  • Connect tensor with pixel and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

A digital image is a grid of numbers, not a picture in any special sense a computer understands. A grayscale image is a 2D array of pixel intensities (0-255); a color image adds a third dimension for channels (Red, Green, Blue), giving a height x width x 3 tensor.

Key concepts

tensorpixelchannelheight x width x channels

Example

import numpy as np
img = np.random.randint(0, 256, size=(224, 224, 3), dtype=np.uint8)
print(img.shape)   # (224, 224, 3) -- height, width, RGB channels
print(img[0,0])     # the RGB values of the top-left pixel, e.g. [120, 45, 200]
Common mistake: Confusing the order of dimensions (height, width, channels) between frameworks — PyTorch defaults to channels-first (C,H,W), while many image libraries use channels-last (H,W,C); mixing them.
02Image preprocessing

What you will learn

  • Apply the standard preprocessing steps before feeding images to a model
  • Explain how resizing changes the behavior, result, or engineering decision in a concrete example
  • Connect resizing with normalization and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

Raw images vary wildly in size, brightness, and scale — preprocessing standardizes them: resizing to a fixed shape the model expects, normalizing pixel values (often to a 0-1 or standardized range), and sometimes converting color spaces.

Key concepts

resizingnormalizationchannel ordering

Example

from torchvision import transforms
preprocess = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),                 # scales pixel values to [0, 1]
    transforms.Normalize(mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225]),
])
Common mistake: Normalizing training images but forgetting to apply the EXACT same normalization at inference time — the model then sees inputs on a totally different scale than it was trained on.
03Convolution fundamentals

What you will learn

  • Compute a simple convolution output by hand
  • Explain how convolution changes the behavior, result, or engineering decision in a concrete example
  • Connect convolution with filter/kernel and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

A convolution slides a small filter (e.g. 3x3 numbers) across the image, computing a weighted sum at each position — this is how a CNN detects local patterns like edges.

Key concepts

convolutionfilter/kernelstridelocal pattern detection

Example

# 1D intuition: filter [1, -1] slides across [3, 3, 3, 8, 8, 8]
# position 0: 3*1 + 3*-1 = 0   (no change -- no edge)
# position 2: 3*1 + 8*-1 = -5  (big change -- an edge!)
# this is exactly what a convolution filter detects, just in 2D
Common mistake: Assuming a convolution 'sees' the whole image at once like a fully-connected layer does — it only looks at a small local window at a time, which is precisely the point (parameter sharing across positions).

06Data augmentation & transfer learning

What you will learn

  • Apply augmentation to expand a small dataset, and reuse a pretrained CV model
  • Explain how data augmentation changes the behavior, result, or engineering decision in a concrete example
  • Connect data augmentation with transfer learning and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

Data augmentation artificially expands your training data by applying realistic transformations (flips, rotations, crops, color jitter) that don't change the true label, teaching the model to be robust to those variations instead of memorizing exact pixel arrangements.

Key concepts

data augmentationtransfer learningfine-tuning

Example

transforms.Compose([
    transforms.RandomHorizontalFlip(),
    transforms.RandomRotation(15),
    transforms.ColorJitter(brightness=0.2),
])
# same image, label unchanged, but the model now sees more variety
Common mistake: Applying augmentations that would change the true label (e.g. flipping an image of a handwritten '6' vertically turns it into something else entirely) — augmentation must preserve the label's correctness.
07Detection, segmentation & evaluation

What you will learn

  • Connect classification vs detection vs segmentation with IoU and predict what changes when one assumption changes

Explanation

Classification answers 'what is in this image' (one label for the whole image). Object detection answers 'what and WHERE' — drawing bounding boxes around each object, evaluated with IoU (Intersection over Union, how well a predicted box overlaps the true box) and mAP.

Key concepts

classification vs detection vs segmentationIoUmAPpixel-level labelsobject detectionaccuracyevaluate

Example

# IoU for a detection box:
# IoU = (area of overlap) / (area of union) between predicted and true box
# IoU > 0.5 is a common 'good enough' threshold for counting a detection as correct
Common mistake: Using plain classification accuracy to judge a detection or segmentation model — these tasks need their own metrics (IoU/mAP, pixel accuracy/mIoU) since there's no single 'right/wrong' label per image.
08Bias and dataset quality

What you will learn

  • Explain how dataset bias changes the behavior, result, or engineering decision in a concrete example
  • Connect dataset bias with representativeness and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

A vision model only knows what its training images showed it. A face-detection model trained mostly on one skin tone or lighting condition will perform worse on others; a medical-imaging model trained on one hospital's equipment may not generalize to another's scanners.

Key concepts

dataset biasrepresentativenesslabel quality

Example

# a real, well-documented failure mode:
# face-detection systems trained predominantly on lighter skin tones
# historically showed measurably higher error rates on darker skin tones
# -- a direct consequence of training data composition, not the algorithm itself
Common mistake: Assuming a high benchmark accuracy number means the model works equally well for everyone in deployment — aggregate accuracy can hide large performance gaps across subgroups.
09Vision transformers: an introduction

What you will learn

  • Connect CNN-based vision to the transformer architecture
  • Explain how vision transformer changes the behavior, result, or engineering decision in a concrete example
  • Connect vision transformer with ViT and predict what changes when one assumption changes
  • Verify the idea with a normal case and an important edge, failure, or scale case

Explanation

Vision Transformers (ViT) offer an alternative to CNNs for image tasks: instead of convolutional filters sliding over the image, the image is split into patches treated like tokens, then processed with the same self-attention mechanism used for text.

Key concepts

vision transformerViTpatches as tokens

Example

# CNN: local filters slide across the image, building up feature hierarchies
# ViT: image patches are tokens, self-attention lets any patch attend to any other
# directly, without the same built-in 'locality' assumption CNNs have
Common mistake: Assuming CNNs are always the right choice for vision tasks -- ViTs are a genuine, increasingly common alternative, especially with large training datasets.
