04Element-wise array operations & vectorization

What you will learn

  • Distinguish matrix and element-wise operators
  • Use .*, ./, and .^
  • Write vectorized expressions

Explanation

Dotted operators apply multiplication, division, or powers element by element. They let one expression operate across an entire vector.

Key concepts

.*./.^element-wisevectorization

Example

a = 1:5;
b = 3:7;
c1 = a .* b;
c2 = a ./ b;
c3 = a .^ b;

Common mistake: Leaving out the dot when the intended operation is element by element.

06Function files & local variables

Files and functions · slides 15–18
MatLab Introduction(1).pdf

What you will learn

  • Write a function declaration
  • Keep a function file separate from the main script
  • Call the function from a script
  • Run the script from the Command Window
  • Match the function name and .m filename

Explanation

A MATLAB function belongs in its own .m function file, while the main script is a separate .m file that calls it. Both files are edited in the Editor. The Command Window is separate: it is where you run the script by name and see output, variables, and figures.

Key concepts

function fileinput variablesoutput variableslocal variablesfilename

Example

% file: calculate_average.m
function average = calculate_average(numbers) % Define a reusable function with one input
total = sum(numbers); % Add all values in the input array
count = length(numbers); % Count how many values are in the array
average = total / count; % Return the arithmetic mean
end % End the function file

% file: grades.m
sam = [87 81 94 90 79]; % Store Sam's grades in the main script
ann = [80 91 88 92 93]; % Store Ann's grades in the main script
sam_average = calculate_average(sam) % Call the function file from the script and display the result
ann_average = calculate_average(ann) % Call the same function with a second array
Common mistake: Putting the main script in the Command Window pane instead of keeping it as a separate .m file in the Editor. • Saving the function under a filename that does not match the function name.

plotxlabelylabeltitlelegendline style

10while loops & switch structures

Programming with MATLAB · slides 30–33
MatLab Introduction(1).pdf

What you will learn

  • Use while when the iteration count is unknown
  • Initialize and update loop state
  • Write switch/case/otherwise

Explanation

while is used when repetition stops after a condition changes rather than after a known number of passes. Its controlling value must be initialized and changed. switch provides a readable alternative for discrete cases.

Key concepts

whileloop conditionstate updateswitchcaseotherwise

Example

x = 5;
while x < 25
    disp(x)
    x = 2*x - 1;
end

switch angle
    case 45
        disp('Northeast')
    otherwise
        disp('Direction Unknown')
end
Common mistake: Writing a while loop whose controlling value never changes.
