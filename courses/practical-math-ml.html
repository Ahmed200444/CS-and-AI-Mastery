01A model is a function

What you will learn

  • Explain what the weight and the bias of a linear model each control
  • Describe training as choosing the values of the weights

Explanation

A model is a function: numbers go in and one number comes out. In the simplest model, predict(x) = w * x + b, the weight w sets the slope and the bias b shifts every prediction up or down. Training does not change the form of the function; it only chooses the values of w and b that make the predictions good.

Key concepts

model as a functionweight (slope)bias (shift)weighted sumtraining as choosing weights

Example

def predict(x, w, b):
    # w is the slope, b is the shift
    return w * x + b

# Same input, different knobs
print(predict(10, w=2.0, b=5.0))   # 25.0
print(predict(10, w=4.0, b=5.0))   # 45.0  doubling w makes the line twice as steep
print(predict(10, w=2.0, b=0.0))   # 20.0  changing b moves the whole line
Common mistake: Thinking training rewrites the function. The form w * x + b stays fixed; only the numbers w and b change.
02Vectors, dot products and similarity

What you will learn

  • Compute a dot product and explain why matrix shapes must line up
  • Use cosine similarity to compare two vectors by direction

Explanation

A row of features is a vector and a dataset is a matrix with one row per example. The dot product multiplies matching positions and adds the results, which is exactly the weighted sum a linear model computes. Cosine similarity divides the dot product by both lengths, so it measures direction only: 1 means the same direction, 0 unrelated and -1 opposite.

Key concepts

vectormatrixdot productshape rulevector length (norm)cosine similarity

Example

import numpy as np

x = np.array([3.0, 1.0, 2.0])    # one example's features
w = np.array([0.5, 2.0, -1.0])   # one weight per feature
print(x @ w)                     # 3*0.5 + 1*2 + 2*(-1) = 1.5

X = np.array([[3.0, 1.0, 2.0], [1.0, 0.0, 4.0]])
print(X @ w)                     # shapes (2, 3) @ (3,) give one prediction per row

def cosine(a, b):
    # dot product divided by both lengths
    return (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))

print(round(cosine(np.array([1.0, 2.0]), np.array([2.0, 4.0])), 2))   # 1.0, same direction
Common mistake: Multiplying arrays whose shapes do not line up. (2, 3) @ (3,) works; (2, 3) @ (2,) raises an error, and most ML shape errors are this rule being broken.
03Probability by simulation

What you will learn

  • Estimate a probability or an average by simulation
  • Explain expected value and variance in plain words

Explanation

You can reason about chance by simulating it many times and counting. A seeded random generator returns the same numbers on every run, which makes an experiment repeatable. The expected value is the long-run average of an outcome and the variance says how spread out the outcomes are around it.

Key concepts

simulationrandom seedexpected valuevariancelaw of large numbers

Example

import numpy as np

rng = np.random.default_rng(42)            # the seed makes the run repeatable
flips = rng.integers(0, 2, size=10_000)    # 0 or 1, ten thousand times
print(flips.mean())                        # close to 0.5

outcomes = np.array([0, 10, 100])
probs = np.array([0.7, 0.25, 0.05])
print(outcomes @ probs)                    # exact expected value: 7.5

draws = rng.choice(outcomes, size=100_000, p=probs)
print(round(draws.mean(), 1))              # the simulated average is close to 7.5
print(round(draws.var(), 1))               # variance: how spread out the draws are
Common mistake: Running an experiment without a seed, so the numbers change on every run and nobody can reproduce the result.
04Distributions and skew

What you will learn

  • Choose between mean and median from the shape of the data
  • Read a percentile such as p95 latency

Explanation

The shape of the data decides which summary is honest. For roughly normal data the mean and the median nearly agree. For right-skewed data such as waiting times, incomes and latencies, a long tail pulls the mean far above the median, so the median and percentiles describe a typical value better.

Key concepts

distributionnormal dataright skewmean versus medianpercentiles (p95)log transform

Example

import numpy as np

rng = np.random.default_rng(0)
normal = rng.normal(loc=50, scale=10, size=5000)     # test scores
skewed = rng.lognormal(mean=2, sigma=1, size=5000)   # waiting times

for name, data in [('normal', normal), ('skewed', skewed)]:
    # mean and median agree only for the normal data
    print(name, round(np.mean(data), 1), round(np.median(data), 1))

# p95: 95% of the values are below this number
print(round(np.percentile(skewed, 95), 1))
Common mistake: Reporting only the mean of skewed data. A few very large values pull it up, so it describes almost none of the real cases.
05Conditional probability and Bayes

What you will learn

  • Compute a posterior probability with Bayes' rule
  • Explain the base-rate mistake for rare events

Explanation

Conditional probability answers 'how likely is A, given that we saw B?'. Bayes' rule combines the base rate of the thing you look for with the detector's hit rate and false-alarm rate. When the thing is rare, even a good detector produces mostly false alarms, which is why rare-event models are judged by precision and recall instead of accuracy.

Key concepts

conditional probabilitybase rate (prior)Bayes' ruleposteriorfalse alarmsprecision

Example

def posterior(prior, hit_rate, false_alarm_rate):
    true_pos = prior * hit_rate                  # really spam and flagged
    false_pos = (1 - prior) * false_alarm_rate   # normal mail that was flagged
    return true_pos / (true_pos + false_pos)

# 1% of mail is spam; the filter catches 90% and wrongly flags 9% of normal mail
print(round(posterior(0.01, 0.90, 0.09), 3))   # 0.092: most flagged mail is not spam

# The same filter when half of all mail is spam
print(round(posterior(0.50, 0.90, 0.09), 3))   # 0.909
Common mistake: Reading a 90% hit rate as '90% of flagged items are real'. With a 1% base rate only about 9% of the flagged items are real.
06Sampling, uncertainty and causation

What you will learn

  • Build a bootstrap confidence interval for a statistic
  • Compare two models on the same test set using the paired difference

Explanation

Every number computed from a sample is uncertain. The bootstrap measures that uncertainty: resample the data with replacement many times, recompute the statistic each time and read the spread as a confidence interval. More data gives a narrower interval, and a correlation between two columns never shows on its own that one causes the other.

Key concepts

sample versus populationbootstrapconfidence intervalpaired comparisoncorrelation is not causationconfounder

Example

import numpy as np

rng = np.random.default_rng(0)
hours = rng.lognormal(mean=2, sigma=1, size=200)   # 200 observed resolution times

medians = []
for _ in range(2000):
    # resample the same number of rows, with replacement
    sample = rng.choice(hours, size=len(hours), replace=True)
    medians.append(np.median(sample))

low, high = np.percentile(medians, [2.5, 97.5])   # a 95% interval
print(round(np.median(hours), 2), round(low, 2), round(high, 2))
Common mistake: Comparing two models by checking whether their separate intervals overlap. When both were scored on the same examples, resample the rows once and look at the interval of the difference.
07Loss and gradients

What you will learn

  • Compute mean squared error and explain what squaring does
  • Estimate a gradient numerically and read its sign

Explanation

A loss function turns 'how wrong is the model?' into one number. Mean squared error squares each miss, so large errors count much more than small ones, and log loss punishes a confident wrong probability heavily. The gradient is the slope of the loss for each weight; it tells you which way to nudge that weight to make the loss smaller.

Key concepts

loss functionmean squared errorlog lossgradientnumerical gradient (central difference)

Example

import numpy as np

def mse(y_true, y_pred):
    return np.mean((y_true - y_pred) ** 2)

print(mse(np.array([3, 5]), np.array([2, 7])))   # (1 + 4) / 2 = 2.5

def loss(w):
    # loss of the model w * 2 against the target 10
    return (w * 2 - 10) ** 2

h = 1e-5
slope = (loss(3 + h) - loss(3 - h)) / (2 * h)    # nudge w each way
print(round(slope, 3))   # -16.0: negative slope, so increasing w lowers the loss
Common mistake: Moving a weight in the direction of the gradient. The gradient points uphill; to reduce the loss you move against it.
08Gradient descent and regularization

What you will learn

  • Train a linear model with gradient descent
  • Explain the effect of the learning rate and of L2 regularization

Explanation

Gradient descent repeats one step: compute the gradient, then move the weights a little against it. The learning rate sets the step size; too small is slow and too large makes the loss jump or explode. L2 regularization adds lam * sum(w ** 2) to the loss, which keeps the weights small and usually helps the model generalise to new data.

Key concepts

gradient descentlearning ratefeature scalingL2 regularizationoverfitting versus underfitting

Example

import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(size=(200, 2))
y = X @ np.array([3.0, -2.0]) + 1.0     # the true weights are 3 and -2, the bias is 1

w, b, lr = np.zeros(2), 0.0, 0.1
for step in range(500):
    err = X @ w + b - y                 # prediction minus target
    grad_w = 2 * X.T @ err / len(y)     # slope of the MSE for each weight
    grad_b = 2 * err.mean()
    w -= lr * grad_w                    # move against the gradient
    b -= lr * grad_b

print(np.round(w, 2), round(b, 2))      # [ 3. -2.] 1.0
Common mistake: Using a learning rate that is too large: the loss jumps around or grows to inf instead of falling. Scale the features and lower the rate.

Write predict(X, w, b) for a linear model. X has one row per example and one column per feature, w has one weight per feature, and b is a number. Return one prediction per row, without a loop.

X @ w gives one number per row; add b to every one of them with + b.

Cosine similarity

Write cosine(a, b) for two 1-D arrays. Return their cosine similarity as a float. If either vector is all zeros, return 0.0 instead of dividing by zero.

Hint

Compute the dot product a @ b and the two lengths with np.linalg.norm. If either length is 0, return 0.0 before dividing.

Find the most similar rows

This is the core of semantic search. Write top_k(query, M, k): M holds one vector per row (say, one per document). Return a list of the row indices of the k rows most similar to query by cosine similarity, best first. On ties, the lower index comes first. No loop over rows.

Hint

Normalise the rows: M / np.linalg.norm(M, axis=1, keepdims=True), and the query the same way. Then scores = Mn @ qn. np.argsort(-scores, kind="stable")[:k] gives the best first, earlier rows first on ties.

Expected value, exact and simulated

Write two functions: expected_value(outcomes, probs): the exact long-run average. simulate_mean(outcomes, probs, n, seed): draw n outcomes at random with those probabilities, using a generator seeded with seed, and return their mean. The same seed must give the same answer.

Hint

Exact: outcomes @ probs. Simulated: rng = np.random.default_rng(seed), then rng.choice(outcomes, size=n, p=probs).mean().

Bayes' rule

A model flags tickets as "urgent". Write posterior(prior, hit_rate, false_alarm_rate): the probability a ticket is really urgent given that it was flagged. prior is the share of tickets that are urgent, hit_rate is how often urgent tickets get flagged, and false_alarm_rate is how often non-urgent tickets get flagged.

Hint

true_pos = prior * hit_rate; false_pos = (1 - prior) * false_alarm_rate; return true_pos / (true_pos + false_pos).

Bootstrap a confidence interval

Write median_ci(values, n_boot, seed) that returns a 95% bootstrap interval (low, high) for the median of values, using a generator seeded with seed.

rng = np.random.default_rng(seed). Repeat n_boot times: rng.choice(values, size=len(values), replace=True) and take its median. Then np.percentile(meds, [2.5, 97.5]) gives the 95% interval.

Compare two models on the same test set

Two models were scored on the same test examples. correct_a[i] and correct_b[i] are 1 if model A (or B) got example i right, else 0. Write paired_bootstrap(correct_a, correct_b, n_boot=2000, seed=0): diff is B's accuracy minus A's accuracy on the full data. Make rng = np.random.default_rng(seed). Then n_boot times: draw idx = rng.integers(0, n, n) (n is the number of examples) and record B's mean minus A's mean on the same rows idx. low and high are the 2.5th and 97.5th percentiles of those differences. Return (diff, low, high) as plain floats.

Hint

Draw one array of row numbers per resample with rng.integers(0, n, n) and index BOTH arrays with it. The difference of their means is one bootstrap value; the 2.5th and 97.5th percentiles of all of them are the interval.

Loss functions

Write mse(y_true, y_pred) and log_loss(y_true, p), where y_true holds 0s and 1s and p holds predicted probabilities of 1. Clip probabilities to [1e-15, 1 - 1e-15] so a probability of exactly 0 or 1 does not produce infinity. Both return a float.

Hint

mse: np.mean((y_true - y_pred) ** 2). log_loss: clip p with np.clip(p, 1e-15, 1 - 1e-15), then -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p)).

Numerical gradient

Write numerical_gradient(f, w, h=1e-5). f takes a 1-D array of weights and returns a number (the loss). Return an array with the slope of f for each weight, using the central difference: nudge one weight up by h and down by h, keeping the others fixed. Do not change w.

Hint

Loop over each position i. Make two copies of w; add h to position i in one and subtract h in the other. The slope is (f(w_plus) - f(w_minus)) / (2 * h).

Gradient descent for linear regression

Write fit(X, y, lr, steps) that trains a linear model with gradient descent on mean squared error, starting from zero weights. Return (w, b, losses), where losses lists the MSE before each update. Your answer should end up matching NumPy's exact least-squares solution.

Hint

Start w = np.zeros(X.shape[1]), b = 0.0. Each step: err = X @ w + b - y; w -= lr * 2 * X.T @ err / n; b -= lr * 2 * err.mean(); append np.mean(err ** 2) to losses.

Add L2 regularization

Write fit_ridge(X, y, lr, steps, lam): gradient descent as before, but the loss is MSE plus lam * sum(w ** 2). The bias b is not penalised. Return (w, b). With lam=0 it must match plain linear regression; bigger lam must shrink the weights.

Hint

Same loop as before, with grad_w = 2 * X.T @ err / n + 2 * lam * w. Do not penalise b.

Weights back in original units

Gradient descent converges much faster on standardised features, but people need weights in the original units ("each extra km adds 0.8 hours"). Write unscale(w_s, b_s, mean, std), which takes weights learned on (X - mean) / std and returns (w, b) that give exactly the same predictions on the raw X. Then write fit_standardised(X, y, lr=0.1, steps=2000): standardise X with its own mean and std, run gradient descent on mean squared error from zero weights, and return the unscaled (w, b). It must match NumPy's least-squares answer to 2 decimal places.

Hint

Fit on Z = (X - mean) / std. A prediction is Z @ w_s + b_s = X @ (w_s / std) + (b_s - (mean / std) @ w_s). So w = w_s / std and b = b_s - (mean / std) @ w_s.

User-item matrix and item similarity

Item-based recommenders start from a user × item matrix. Write item_similarity(ratings), where ratings is a DataFrame with columns user, item, rating: Pivot to a matrix with one row per user and one column per item (missing ratings are missing). Mean-centre each user's row: subtract that user's average rating, so a generous rater's 4 and a harsh rater's 4 are comparable. Then fill missing values with 0. Return a DataFrame of cosine similarities between items (items as both index and columns, sorted by item name). An item with no variation has similarity 0 with everything else (not NaN), and 1.0 with itself.

Hint

M = ratings.pivot_table(index='user', columns='item', values='rating'). Subtract each row's mean with M.sub(M.mean(axis=1), axis=0), then fillna(0). Cosine between item columns: normalise each column and take V.T @ V.
